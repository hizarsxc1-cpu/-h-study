# H STUDY

**Your Smart Study Companion** — a lightweight Android study planner with a dark purple interface.

## Features
- Dashboard with task summary and quick actions
- Task list with completion tracking
- Class schedule manager
- Subject notes
- Study goals
- Progress statistics
- Local SQLite storage (data stays on the device)

## Build
GitHub Actions builds a debug APK on every push to `main`. Open the Actions tab and download the `h-study-debug-apk` artifact after a successful run.

## App details
- Package: `com.hstudy.app`
- Minimum Android: 6.0 (API 23)
- Target SDK: 35
